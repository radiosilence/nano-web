- **macOS CI runs as one job, and only when needed.** The account's macOS runners are few and shared by every repository, so a single `Apple` job runs every macOS step on one runner. Pull requests take it only when they change dependencies, toolchain, build configuration, workflows or Apple-gated code, and run clippy and the tests; a release pull request also builds the release binary, unsigned. Main takes it only to release, and the scheduled run takes it to run the checks and save the cache that pull requests restore.
